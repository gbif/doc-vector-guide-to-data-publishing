resources to facilitate data publishing in GBIF. For convenience, links
are organized by category.

Controlled vocabulary & ontologies

* https://rs.gbif.org/vocabulary/dwc/basis_of_record_2022-02-02.xml[+++Darwin
Core Basis of Record Vocabulary+++]: definitions for terms used to
populate basisOfRecord
* Metadata descriptors for health:
https://decs.bvsalud.org/en/[+++DeCS/MeSH+++],
https://www.globalindexmedicus.net/[+++Global Index Medicus+++],
https://www.nlm.nih.gov/research/umls/index.html[+++Unified Medical
Language System (UMLS)+++]  
* Repository for biomedical ontologies:
https://www.ebi.ac.uk/ols4/[+++EMBL-EBI Ontology Lookup Service+++] ,
for ontologies on habitat, e.g.
https://www.ebi.ac.uk/ols4/ontologies/envo/classes/http%253A%252F%252Fpurl.obolibrary.org%252Fobo%252FENVO_03501257[+++barn+++];

https://ontobee.org/ontology/NCIT?iri=http://purl.obolibrary.org/obo/NCIT_C16553[+++ELISA+++];

* For more general health information, the
https://www.healthit.gov/topic/standards-technology/standards/fhir[+++HL7®
FHIR®+++] is an interoperability standard designed to enable health data
sharing.

to divide scientific names into their components and to check them
against the taxonomic backbone used by GBIF
* GBIF's https://www.gbif.org/tools/species-lookup[+++species
lookup+++]: to normalize species names against the GBIF backbone
* https://www.checklistbank.org/[+++ChecklistBank+++]
* https://data.canadensys.net/tools/dates#:~:text=Use%20this%20tool%20to%20parse,a%20tab%20or%20a%20pipe.[+++Canadensys
Date parser+++]: tool to parse dates into component parts
* A
https://discourse.gbif.org/t/a-guide-to-date-issues/4185[+++guide+++] to
date issues
* https://discourse.gbif.org/t/how-to-handle-the-event-dwc-fields-for-trap-base-occurrence/3162/4[+++How

Quality control tools & resources

* Data quality
https://ipt.gbif.org/manual/en/ipt/latest/data-quality-checklist[+++checklist+++]
* GBIF's https://www.gbif.org/tools/data-validator[+++data validator+++]
* Zermoglio PF, Plata Corredor CA, Wieczorek JR, Ortiz Gallego R &
Buitrago L (2021) Guía para la limpieza de datos sobre biodiversidad con
OpenRefine. Versión 3. Copenhagen: GBIF Secretariat.
https://doi.org/10.15468/doc-gzjg-af18[+++https://doi.org/10.15468/doc-gzjg-af18+++]
* https://openrefine.org/[+++OpenRefine+++] free, open source tool for
cleaning data.
* https://hbiostat.org/r/hmisc/[+++Hmisc R package+++] for summarizing
data, useful for checking data quality and outliers
* https://bionomia.net/[+++Bionomia+++], is an online platform that
links people to specimens specimens
(https://pmc.ncbi.nlm.nih.gov/articles/PMC9836581/#B8055638[+++Shorthouse
2020+++]), and allows for name disambiguation when one collector has
used different names, or a name is written in more than one way. The
specimen data associated with the terms
http://rs.tdwg.org/dwc/terms/recordedBy[+++recordedBy+++],
http://rs.tdwg.org/dwc/terms/recordedByID[+++recordedByID+++],
http://rs.tdwg.org/dwc/terms/identifiedBy[+++identifiedBy+++],
http://rs.tdwg.org/dwc/terms/identifiedByID[+++identifiedByID+++] are
used by Bionomia to generate attribution.

* https://zenodo.org/record/6453921#.Y9KsQkHMKmU[+++Excel to Darwin Core
Standard (DwC) Tool+++]: creates templates for Event, Occurrence,
MeasurementsOrFacts, Extended MeasurementsOrFacts (EMoF), and Simple
Multimedia tables.
* https://sios-svalbard.org/aen/template-generator/[+++Darwin Core
Template Generator for Event and Occurrence tables+++]: user can choose
DwC terms to generate template for Event and Occurrence tables,
developed by the Nansen Legacy project.
* Template
https://gbif-norway.github.io/dwc-excel-template-generator-js[+++generator+++]
by GBIF Norway
* Table converter from columns to rows
https://mycena.sibbr.gov.br/[+++https://mycena.sibbr.gov.br/+++] by GBIF
Brazil - SiBBr (in Portuguese).
